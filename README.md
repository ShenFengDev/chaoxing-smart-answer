# 超星智答 · ChaoxingSmartAnswer

> 学习通自动答题、刷课的助手：**6 大题库并行 + AI 双引擎**，带语境注入、答案复核与接口可视化。

## 这是什么

一个跑在 Tampermonkey 里的超星学习通辅助脚本。核心思路是「**多来源并行取答 + 交叉复核**」，而不是只赌一个题库：

- 点开一道题，**6 个题库同时并发查询**，谁先有答案用谁的
- 答完再用题库**反向投票复核**，2 票以上一致且与当前填写不同才改
- 题库都没有时，交给 **AI** 兜底
- 全过程在**接口日志面板**里可见：谁答的、耗时多少、命中与否

## 功能

### 答题引擎

| 能力 | 说明 |
|---|---|
| 6 大在线题库 | 题库海 / 一之 / 言溪 / muketool / LIKE 知识库 / ZE 题库，**多选开关**，可单独关闭 |
| 自定义题库 | 兼容 `code` / `data` / `result` / `content` 等 8 种返回结构，字母答案自动映射为选项 |
| AI 作答 | 任意 OpenAI 兼容接口；**模型列表一键拉取**，模型名写错自动纠正并重试 |
| 语境注入 | 每条请求自动带上**课程名 + 目录章节 + 大题标题**，不再脱离教材语境 |
| 答案复核 | 多库投票，2 票推翻当前答案；简答/论述只给参考、不判错 |
| 垃圾过滤 | 自动拦截「本题答案在付费题库中…」这类引流文案 |
| 性能 | 答案缓存 30 分钟 + 并发去重，复核环节零重复请求 |

### 全流程自动化

| 场景 | 能力 |
|---|---|
| 章节任务点 | 视频 / 音频 / 文档 / 作业 / 讨论，支持「重做已完成任务点」 |
| 考试 | 整卷逐题作答（路由识别 + DOM 兜底），可选自动切换与**自动交卷（默认关）** |
| 讨论 | AI 生成简短发言，参考同学观点，**英文题强制英文作答**（含输出校验重试） |

### 可观测 / 可控制

- **接口日志面板**：时间、渠道、耗时、状态、命中、内容摘要，实时刷新，可暂停刷新
- **暂停按钮**：任意时刻停下（快捷键 `Alt+P`），已答内容保留，恢复后从当前题继续
- **弹窗缩放**：右下角拖拽改大小，双击复位，尺寸自动记忆

## 快速开始

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)
2. 新建脚本，粘贴 [`chaoxing-smart-answer.user.js`](./chaoxing-smart-answer.user.js) 全文，保存
3. 打开超星章节页，右下角出现悬浮面板即成功
4. 点「打开配置」按需填写题库密钥 / AI 密钥，**保存后刷新页面**

> 想纯 AI 作答：开启「仅AI模式」，题库渠道全部不查询。

## 常见问题

**Q：题库都没反应？**
打开左下角「📡 接口日志」，每个渠道的 HTTP 状态、耗时、返回摘要都列出来了。常见原因：密钥未填、地址不通、接口变更。

**Q：AI 答非所问 / 模型不存在？**
确认已填密钥，并在「AI 模型名称」点过「获取模型列表」。模型名**区分大小写**（`glm-4.5` ≠ `GLM-4.5`）。脚本遇到 `model_not_found` 会自动纠正并重试。

**Q：会自动交卷吗？**
不会。「考试自动交卷」默认关闭，需要你手动开启；交卷不可撤回。

**Q：讨论题答成中文？**
英文题会自动用英文强指令，并过滤掉中文参考回复；若模型仍答中文，会带更强指令重试一次。
