# 题库接口清单

本文列出脚本会调用的**全部外部接口**，方便你了解数据流向、自行测试或接入自己的题库。

> 所有请求都由 `GM_xmlhttpRequest` 发出（绕过 CORS），超时统一在 12–90 秒之间。
> 未填密钥的渠道会被**自动跳过**，不会产生任何请求。

---

## 总览

| # | 渠道 | 接口地址 | 方法 | 鉴权位置 | 密钥字段 | 是否免费 |
|---|---|---|---|---|---|---|
| 1 | 题库海 | `http://api.tikuhai.com/search` | POST | 请求体 `key` + 请求头 `key` | `thtoken` | 部分免费，完整需付费 |
| 2 | 一之题库 | `http://cx.icodef.com/wyn-nb?v=4` | POST | 请求头 `Authorization` | `yztoken` | 免费（限速） |
| 3 | 言溪题库 | `https://tk.enncy.cn/query` | POST | 请求体 `token` | `enncytoken` | 免费 |
| 4 | muketool | `https://api.muketool.com/cx/v2/query` | POST | 无需鉴权 | — | 免费 |
| 5 | LIKE 知识库 | `https://app.datam.site/api/v1/query` | POST | 请求头 `Authorization: Bearer` | `customApiKey` | 按点数计费 |
| 6 | ZE 题库 | `https://api.zaizhexue.top/api/query` | POST | 请求头 `Authorization: Bearer` | `zetoken` | 按账号额度 |
| 7 | 自定义题库 | 你自己填 | POST | 可选 `Authorization: Bearer` | `customApiKey` | 取决于你 |
| 8 | AI | 你自己填（OpenAI 兼容） | POST | 请求头 `Authorization: Bearer` | `aiApiKey` | 取决于服务商 |

## 1. 题库海

```
POST http://api.tikuhai.com/search
Content-Type: application/json
key: <thtoken>

{
  "key": "<thtoken>",
  "question": "题干文字",
  "options": ["选项A", "选项B"],
  "type": "0"
}
```

**响应**

```json
{
  "code": 1,
  "data": { "answer": "A", "num": 199, "usenum": 3 },
  "msg": "备注"
}
```

- `code === -1` 表示需要付费/无权限，此时 `msg` 会作为提示返回
- `data.answer` 可能是选项原文，也可能是 `A` / `A#B` 形式的字母

**密钥获取**：题库海官网购买后填写到「基础配置 → 题库海秘钥」

## 2. 一之题库

```
POST http://cx.icodef.com/wyn-nb?v=4
Content-Type: application/json
Authorization: <yztoken>

{ "question": "题干文字" }
```

**响应**

```json
{ "code": 1, "data": "答案1#答案2" }
```

- 多答案用 `#` 分隔
- 返回内容若含「叛逆 / 公众号 / 一之」等推广词会被**自动丢弃**
- 请求会随机伪造 `X-Forwarded-For` / `X-Real-IP` 以规避限流

## 3. 言溪题库

```
POST https://tk.enncy.cn/query
Content-Type: application/json

{ "token": "<enncytoken>", "title": "题干文字" }
```

**响应**

```json
{ "code": 1, "data": { "answer": "答案内容" } }
```

## 4. muketool

```
POST https://api.muketool.com/cx/v2/query
Content-Type: application/json

{ "question": "题干文字", "type": 0 }
```

**响应**

```json
{ "code": 1, "data": "答案1#答案2" }
```

- 无需密钥，免费的公共接口
- `type` 为数字：0 单选 / 1 多选 / 2 填空 / 3 判断

## 5. LIKE 知识库（datam.site）

> ⚠️ 这是**生成式判题接口**，不是传统的"题干查库"，返回结构化答案 + 置信度，按点数计费。

### 5.1 答题

```
POST https://app.datam.site/api/v1/query
Content-Type: application/json
Authorization: Bearer <customApiKey>

{
  "v": "2",
  "title": "题干文字",
  "options": "选项A\n选项B\n选项C",
  "type": "single",
  "images": [],
  "suggestion_title": "",
  "suggestion_options": ""
}
```

`type` 取值：`single` / `multiple` / `judgement` / `completion`

**响应**

```json
{ "questionType": "CHOICE",        "answer": { "selectedOptions": ["A", "C"] }, "confidence": 0.95 }
{ "questionType": "FILL_IN_BLANK", "answer": { "blanks": ["答案1", "答案2"] },   "confidence": 0.88 }
{ "questionType": "JUDGMENT",      "answer": { "isCorrect": true },             "confidence": 0.99 }
```

### 5.2 模型列表

```
GET https://app.datam.site/api/v1/query/models
Authorization: Bearer <customApiKey>

{ "models": ["deepseek-v3.2", "glm-4.5", "gpt-5"], "message": "..." }
```

### 5.3 余额查询

```
GET https://app.datam.site/api/v1/balance
Authorization: Bearer <customApiKey>

{ "balance": 1500, "message": "..." }
```

**密钥获取**：注册 [datam.site](https://www.datam.site) 后在控制台创建 API Key

## 6. ZE 题库（zerror）

```
POST https://api.zaizhexue.top/api/query
Content-Type: application/json
Authorization: Bearer <zetoken>

{
  "v": "2",
  "title": "题干文字",
  "options": "选项A\n选项B",
  "type": "single",
  "images": [],
  "suggestion_title": "",
  "suggestion_options": ""
}
```

**响应**

```json
{ "data": { "code": 1, "data": "答案1#答案2", "msg": "来自题库" }, "success": true }
```

- `code === 1` 命中，`code === 0` 未找到或 token 无效
- 多答案用 `#` 分隔
- 也支持 GET：`https://api.zaizhexue.top/api/query?token=xxx&title=xxx`

**密钥获取**：登录 [tiku.zerror.cc](https://tiku.zerror.cc) → 我的 → 题库配置

## 7. 自定义题库

脚本会向你填写的地址发：

```
POST <你的地址>
Content-Type: application/json
Authorization: Bearer <customApiKey>   // 填了密钥才带

{
  "question": "题干文字",
  "type": "0",
  "options": ["选项A", "选项B"],
  "key": "<customApiKey>"
}
```

**响应兼容以下全部结构**（任选其一即可）：

```json
{ "code": 1,   "answer": "A" }
{ "code": 0,   "data": { "answer": "答案" } }
{ "code": 200, "data": { "answer": "答案" } }
{ "status": 0, "result": ["A", "C"] }
{ "answer": "答案" }
{ "success": true, "data": "A,C" }
{ "code": 1, "data": { "answer": ["A"] } }
"纯文本答案"
```

**地址写法**：`http://` 可省略，脚本会自动补全；HTTP 失败会自动重试 HTTPS。

## 8. AI 接口（OpenAI 兼容）

```
POST <你的 aiApiUrl>
Content-Type: application/json
Authorization: Bearer <aiApiKey>

{
  "model": "deepseek-chat",
  "messages": [{ "role": "user", "content": "<完整提示词>" }]
}
```

**响应**（标准 chat/completions）

```json
{ "choices": [{ "message": { "content": "A" } }], "usage": { "prompt_tokens": 320, "completion_tokens": 5 } }
```

内置可选服务商：

| 服务商 | 地址 |

| DeepSeek | `https://api.deepseek.com/v1/chat/completions` |
| OpenAI | `https://api.openai.com/v1/chat/completions` |
| Google Gemini | `https://generativelanguage.googleapis.com/v1beta/openai/chat/completions` |
| 阿里通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions` |
| 月之暗面 Kimi | `https://api.moonshot.cn/v1/chat/completions` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4/chat/completions` |
| 百度文心 | `https://qianfan.baidubce.com/v2/chat/completions` |

## 调用策略

```
① 每题同时并发请求：自定义题库 + 勾选的在线题库 + AI
② 按优先级排序展示：自定义题库 > 在线题库（按勾选顺序）> AI
③ 收集全部返回后用题库投票复核（2 票推翻）
④ 命中结果缓存 30 分钟，同题干不重复请求
```

**关掉某个渠道**：配置 → 在线题库 → 取消勾选，该渠道完全不发请求。
